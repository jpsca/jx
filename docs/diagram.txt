  │        ┌──────────────────────────────────────────────────────────┐    │

  │        │                     ↓                                     │    │
  │        │ props = {title: "Hi"}          (declared in {#def})      │    │

  │        └──────────────────────────────────────────────────────────┘    │
  │                                                                         │
  │     b) CREATE ATTRS OBJECT                                              │
  │        ┌──────────────────────────────────────────────────────────┐    │
  │        │ Attrs(extra)                                              │    │
  │        │   - Lazy evaluation (values not stringified yet)         │    │

  │        └──────────────────────────────────────────────────────────┘    │
  │                                                                         │
  │     c) BUILD RENDER CONTEXT                                             │
  │        ┌──────────────────────────────────────────────────────────┐    │

  │        │   title: "Hi",           # declared props                 │    │

  │        │   _slots: {...},         # named slot content             │    │
  │        │   _get: <fn>,            # child component loader         │    │

  └─────────────────────────────────────────────────────────────────────────┘
